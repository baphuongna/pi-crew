# US-021 — Run comparison (before/after)

## Status

planned

## Lane / Priority

normal · P3

## Source

- `docs/stories/backlog.md` — DX epic, US-021 (planned).

## Problem

Comparing two runs (e.g. before/after a fix, or two attempts of the same
goal) requires manual inspection of two run dirs: manifests, tasks, events,
cost. No tooling exists; `pi-crew` has all the data (manifest, tasks,
events, usage) but no diff.

## Goals / Non-goals

- `team action='compare' runIds=[a,b]` producing a structured diff:
  status, task-by-task status/duration/tokens/cost deltas, event-timeline
  phases, model routing differences, and (when both exported) artifact
  hash differences.
- Markdown output via the existing export writer (`writeArtifact`) so it
  can be reviewed/attached (US-022).
- NOT in scope: visual diff UI (that's US-020 territory), git integration.

## Design

Anchors: `src/extension/run-export.ts` (`exportRunBundle` — reuse its
redaction + bundle shape), `src/ui/run-snapshot-cache.ts` (task/agent
snapshots), `src/state/stores/run-metrics.ts` (usage/cost).

Proposal:

1. New handler `handleCompare({ runIds: [a, b] })` in the team-tool
   dispatch layer (alongside `handleStatus`/`handleExport`), gated on both
   runs resolving via `loadRunManifestById` (cross-root safe after F-L1).
2. Build a `RunComparison` object:
   - `status: { a, b }`
   - `tasks: [{ id, statusA, statusB, durationDeltaMs, tokensDelta,
     costDelta }]`
   - `events: { addedTypes, removedTypes, phaseDurations }`
   - `models: { routingDiff }`
3. Render markdown + write artifact `compare/<runA>__<runB>.md`.
4. Deterministic output (no wall-clock in the body — reuse the pinned-clock
   pattern from `docs/ui-samples/capture.ts` / `spinnerClockNow`) so the
   comparison is diffable and testable.

## Acceptance Criteria

1. Same-run comparison (`a === b`) shows zero deltas (self-consistency
   invariant — an excellent test).
2. Different statuses/tasks produce accurate per-field deltas.
3. Output markdown is byte-stable across repeated calls (no timestamps in
   the body; the artifact's own `createdAt` is metadata only).
4. Missing run id → clear error, no partial artifact.
5. Artifact written under the FIRST run's artifactsRoot.

## Validation

| Layer | Test | Expected |
|-------|------|----------|
| Unit | `test/unit/extension/compare-runs.test.ts` (new) | self-diff zero; known-delta fixtures; determinism (2 calls byte-equal); missing-id error |
| Mutation | drop a field from the diff | fixture test RED |
| Gates | `npm run test:critical` · `npm run typecheck` · biome | green |
