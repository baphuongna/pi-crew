# RM-01 — MINOR 2: `peekPendingCoalescedWrite` shallow copy at serve time

## Status

planned

## Lane / Priority

tiny · P2 (latent aliasing bug)

## Source

- `docs/stories/backlog.md` — "Deferred — review-round 2026-09-17", MINOR 2.
- Anchors verified 2026-09-22:
  `src/state/atomic-write.ts:1161` (`peekPendingCoalescedWrite<T>`),
  consumer `src/runtime/crew-agent-records.ts:310` (`readCrewAgents`).

## Problem

`peekPendingCoalescedWrite` returns the pending in-memory object **by
reference**. Today's callers are read-only, so it is safe — but any future
caller that mutates the returned object would corrupt the coalesced write
buffer (a write-then-flush path). This is a classic shared-mutable-state
footgun and the review flagged it as MINOR.

## Design

Return a shallow copy from the peek API (or from the serving call site):

```ts
export function peekPendingCoalescedWrite<T>(filePath: string): T | undefined {
  const pending = pendingCoalesced.get(filePath);
  if (!pending) return undefined;
  return shallowClone(pending.value);   // T is JSON-shaped in all uses
}
```

- Because all uses are JSON-shaped, a shallow clone (`{...v}` for objects,
  `[...v]` for arrays, `structuredClone` if nested mutation is plausible)
  suffices. Prefer `structuredClone` if the payload is nested (agent records
  contain nested usage/attempts) and the cost is acceptable on this path
  (call-site is `readCrewAgents`, not a hot tick).
- Alternatively make the copy explicit at the call site with a comment — but
  API-level is safer (protects all future callers).

## Acceptance Criteria

1. Mutating the value returned by the peek API does NOT affect the pending
   buffer (test: peek → mutate → peek again → unchanged).
2. `readCrewAgents` returns data that is safe for callers to mutate without
   affecting subsequent reads (test).
3. No behavior change for read-only callers; existing suites green.
4. Nested-field protection: mutating a nested object (e.g. `usage.input`)
   also does not leak (this is why `structuredClone` > shallow spread).
