### 1.3 Output trong transcript (tool renderers)

Chỉ **2 tool** có renderer custom: `team` và `agent`.

- `team` — **RAIL card (R3, 2026-09-16)**: `┏ CREW ▸ <team>` canopy + `┃ goal`; streaming → `┃ ⠸ n/m · pct% ▕███▎░░▏ ···· <elapsed>` + dòng agent phụ; collapsed → `┗ ● n/m · <team> · dur · tok · $cost ···· ctrl+o`; expanded → gauge + per-agent row `✓ role (model) N tools · dur` + `↑in ↓out $cost` + cap `┗ <team> · … ctrl+o`. Action khác `run` → canopy word là action (`┏ STATUS ▸ <runId8>`).
- `agent`: `┏ AGENT ▸ <name>` + prompt; running → `┃ ⠸ <name> ···· <elapsed> · <tok/s> · <tool>`; collapsed → `┗ ● <name> <dòng output đầu> ···· ctrl+o`; expanded → rows + cap.
- Ngôn ngữ dùng chung: rail dọc `┏┃┗` (màu theo trạng thái), dot-leaders `····` nối trái–phải, gauge `▕█▏` độ chính xác 1/8 ô. Card **width-adaptive** (build tại width render).
- **Brief mode** (`/crew-brief on|off|status`): 1 dòng `✓ 3/4 tasks · 1m2s · 12k tok` — chỉ áp dụng cho `team`/`agent`; `team action=run` luôn bypass.
- **DWF phase display**: `▶ phase` / `⏸` trong Progress pane, wired thật qua `progress-pane.ts:26`.
- **crew-vibes** (`/team-vibes on|off`): quota provider lên footer native — `provider 5h ━━━╌╌ 45% 2h30m Wk ━╌╌ 23%`.
