## Sprint 5 — Large refactor (3 findings, L, ~9-12 days solo / 5-6 parallel)

### NON-NEGOTIABLE: Characterization tests BEFORE refactor
Mỗi finding cần 1-1.5 ngày viết characterization tests lock current behavior TRƯỚC khi extract. Nếu không có time budget → **defer refactor**, không skip tests.

### Findings
| ID | Target | Strategy | Effort |
|----|--------|----------|--------|
| **CORE-4** | `team-runner.ts` executeTeamRunCore (~1075 dòng, 12 early-return, 15 mutable locals) → `scheduler/` 8 functions + `SchedulerContext` state bag | Incremental (1 function/PR) | L (~4-5d) |
| **CORE-5** | `task-runner.ts` runTeamTask (~1215 dòng) → `task-runner/child-executor.ts` + pre/post-execution.ts | Incremental (live-executor đã prove pattern) | L (~3-4d) |
| **API-5** | 54-action mega-tool → **facade pattern** (keep `handleTeamTool`, split schema+dispatch internal thành 5 domains) | Schema split + dispatch router | M-L (~3d) |

### KEY API-5 decision: FACADE, không register 5 tools
**Handlers ĐÃ extracted** vào `src/extension/team-tool/*.ts` (40+ files). Monolith chỉ là schema + dispatch switch. Split internal thành 5 domain schemas (`RunDomainParams`, `StatusDomainParams`, ...) + 5 router functions. `handleTeamTool` giữ làm public API → **zero caller changes**. Register 5 separate pi tools = Phase 2 future, KHÔNG Sprint 5.

### 54 actions → 5 domains
- `team.run` (10): run, parallel, plan, chain, goal, orchestrate, resume, retry, wait, steer
- `team.status` (16): status, list, get, events, artifacts, summary, graph, search, health, worktrees, checkpoint, cache, explain, onboard, recommend, help
- `team.control` (8): cancel, invalidate, respond, cleanup, prune, forget, doctor
- `team.manage` (16): create, update, delete, init, config, validate, autonomy, settings, workflow-*, import, imports, export
- `team.automate` (6): schedule, scheduled, anchor, auto-summarize, auto_boomerang, api

### Defer/acceptance framework
ALL 3 findings meet "Incremental" criteria (test <70%, >500 LOC, >8 returns, >5 mutable). **Big-bang NOT acceptable**. Exception: nếu characterization >90% branch + differential testing pass → consolidated CORE-4 PR (2-3 extractions) OK.

### Critical risks
- R1: CORE-4 cancel-path regression → `SchedulerDecision.return` funnel qua finally
- R2: CORE-4 merge race regression → keep `withRunLock` + `loadRunManifestById` exactly
- R3: CORE-5 timeout/listener leak → assert `externalAbortListener` removed
- R4: API-5 schema tightening rejects valid calls → keep `additionalProperties: true` Phase 1
