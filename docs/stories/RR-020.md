### A0-1 — Resolver marker unification (fix bug HAI ROOT, HIGH)

`src/utils/paths.ts:114` dùng 15 marker (gồm `.pi`/`.crew`) trong khi
`src/state/crew-init.ts:167` chỉ dùng 7 (`.git`/`.hg`/`.svn` + 4 file). Với
cwd=`parent/subproject` có `parent/.git` + `parent/subproject/.pi`:
resolver đọc `subproject/.pi/teams`, initializer **tạo** `parent/.crew` → hai
root cho một run (reachable qua `run-intent.ts:183-184`).

**Fix:** tách hằng số dùng chung `src/utils/project-markers.ts` (KHÔNG import
gì — an toàn dưới jiti/ESM namespace race issue #28); cả hai resolver đọc từ đó.

- `src/utils/project-markers.ts` (mới), `src/utils/paths.ts`, `src/state/crew-init.ts`

### C-1 — Cache key thiếu `goal` (BR-06, correctness P1)

`stableIOCacheKey(cwd, stepTask)` thiếu `manifest.goal` trong khi giá trị cache
phụ thuộc goal (`runRetrievalCycle`, `buildKnowledgeFragment`). Run B nhận
suggested-files/knowledge của goal A. Reachable: goal-loop (goal đổi mỗi turn,
cùng step template) + chain steps.

**Fix:** key = `(cwd, stepTask, goal)`. KHÔNG đổi scope của `clearStablePrefixCache()`
(đổi scope trước key sẽ gây hồi quy cross-goal). `role` cố ý không thêm — không scored.

- `src/runtime/task-runner/prompt-builder.ts`
- Test: `test/unit/runtime/task-runner/prompt-builder-cache-goal.test.ts`

### C-2 — Cursor continuation contract (BR-08)

Nhánh `fromByteOffset` đọc hết delta, cắt theo `limit`, nhưng trả
`nextByteOffset` sau TOÀN BỘ delta ⇒ resume từ đó bỏ qua đuôi chưa giao.

**Fix:** chỉ trả `nextByteOffset` khi đã giao hết delta; tài liệu hóa `nextSeq`
là continuation token chính (đã đúng sẵn: max seq của event đã giao).

- `src/state/event-log/cursor.ts`
- Test: `test/unit/state/event-log/event-log-cursor-limit-continuation.test.ts`

### C-3 — Shadow discriminator theo cấu trúc (BR-09)

`isDelegateShadowTask` = `agent === "delegate"` ⇒ task workflow hợp lệ có agent
tên `delegate` bị loại khỏi mọi batch ⇒ run `blocked` im lặng.

**Fix:** `stepId === undefined` (shadow broker mint không có `stepId`; mọi task
scheduler có). Không đổi schema ⇒ tương thích state cũ hai chiều. Không thêm
`delegate` vào protected-name.

- `src/runtime/broker/delegate/shadow-lifecycle.ts`, `src/runtime/dispatch-batch.ts`
- Test: `test/unit/runtime/broker/shadow-task-dag-readiness.test.ts`, `delegate-shadow-lifecycle.test.ts`
