## Lessons learned (process)

1. **Verify phải kèm measurement** — F-05 reasoning-said-FP nhưng benchmark prove REAL. Đừng tin lý thuyết regex ReDoS, benchmark adversarial input.
2. **Team planner có drift** — truyền analysis chi tiết vẫn có thể bị planner pick findings khác (ưu tiên S-effort). Cần goal cực rõ + explicit file list + anti-scope-creep warning.
3. **Executor "already applied" artifact** — parallel execution trong shared single-workspace: executor sau thấy thay đổi của executor trước → tưởng "previous attempt". Phân biệt khó.
4. **Line refs become stale fast** — mỗi refactor сдвига line numbers. Verify bằng grep symbol, không tin line number.
5. **Reasoning-only verification insufficient cho perf/security claims** — luôn benchmark/measure.
6. **Reports have ~22% inaccuracy** — count inflation, false positives, stale lines, path errors. Independent verify đáng giá.
